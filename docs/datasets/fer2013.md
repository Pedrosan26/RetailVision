# FER-2013 dataset — emotion classification prep (RV-003)

## Source

User-provided (already present in the working directory) — the standard
`msambare/fer2013` Kaggle repackaging of FER-2013 as folder-per-class JPEGs.
Moved from `data/FER-2013/` to `data/fer2013/raw/` (gitignored — not
committed) to match the lowercase path convention and the `raw/`/`processed/`
split used for [[utkface]].

Verified against the documented FER-2013 format:

- 35,887 images total: 28,709 in `raw/train/`, 7,178 in `raw/test/` — exactly
  matches FER-2013's canonical counts (the 7,178 test figure is the combined
  public + private test sets from the original Kaggle competition).
- All images are 48×48 grayscale JPEGs. 0 images failed that check.
- All 7 expected class folders present in both splits: `angry`, `disgust`,
  `fear`, `happy`, `neutral`, `sad`, `surprise`. No unexpected folders.

## Format decision: classification, not detection

Same reasoning as UTKFace: these are already single pre-cropped 48×48 face
images, so emotion is a classification task on a crop the upstream face
detector already produced, not a localization task. Laid out as a YOLOv8
classification dataset (`yolov8n-cls`-compatible folder-per-class), no
bounding boxes.

## Split: official test kept intact, val carved from train

FER-2013 ships with only `train/` and `test/` — no validation split. The
official `test/` set is used as-is for final evaluation and is never
touched or reshuffled. A stratified 10% validation split is carved out of
`train/` only (per-class, seed 42) so training can be monitored (early
stopping, checkpoint selection) without contaminating the held-out test set.

```
data/fer2013/processed/
  train/<emotion>/*.jpg   (symlinks into raw/train/, 90% per class)
  val/<emotion>/*.jpg     (symlinks into raw/train/, 10% per class, carved out)
  test/<emotion>/*.jpg    (symlinks into raw/test/, untouched official test set)
  distribution_report.json
```

## Class distribution (35,887 images)

| Emotion | Train | Val | Test | Total | Share of total |
|---|---|---|---|---|---|
| Happy | 6,493 | 722 | 1,774 | 8,989 | 25.0% |
| Neutral | 4,469 | 496 | 1,233 | 6,198 | 17.3% |
| Sad | 4,347 | 483 | 1,247 | 6,077 | 16.9% |
| Fear | 3,687 | 410 | 1,024 | 5,121 | 14.3% |
| Angry | 3,595 | 400 | 958 | 4,953 | 13.8% |
| Surprise | 2,854 | 317 | 831 | 4,002 | 11.2% |
| Disgust | 392 | 44 | 111 | 547 | **1.5%** |

Two known problem classes, confirmed here rather than just asserted:

- **Disgust is severely underrepresented** — 547 images total, ~16x smaller
  than Happy and less than a fifth the size of the next-smallest class
  (Surprise, 4,002). With only 44 validation and 111 test images, per-class
  metrics for this class will be noisy just from small-sample variance, not
  only model weakness. Expect this to be the hardest class to get a reliable
  read on, and don't over-index on a single bad/good disgust score.
- **Fear is not undersized by count** (5,121 images, close to Angry/Surprise)
  but is documented in the FER-2013 literature as noisy and frequently
  confused with Sad and Surprise, since the visual cues overlap heavily at
  48×48 resolution. Watch the confusion matrix, not just recall, for this
  class during evaluation.

No corrective resampling is applied at this stage. Recommendation for the
training step (RV-004): report a full per-class confusion matrix (not just
accuracy) so Disgust/Fear confusion patterns are visible, and consider
class-weighted loss for Disgust specifically if its recall is materially
worse than the other six classes after a baseline run.

## Supplementary dataset: AffectNet

If FER-2013 accuracy proves insufficient after training and augmentation
tuning (RV-004) — particularly if Disgust recall stays too low to be useful,
or Fear/Sad/Surprise confusion doesn't improve — **AffectNet** is identified
as the supplementary fallback, per the project's literature review. AffectNet
is substantially larger and includes higher-resolution, more varied images
per emotion class, which could help specifically with the underrepresented
Disgust class. Not downloaded or evaluated in this phase; noted here so a
future contributor doesn't have to re-derive this decision from scratch if
FER-2013 alone underperforms.
